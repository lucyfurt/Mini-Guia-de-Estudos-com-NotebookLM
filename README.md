# 📖 Mini Guia de Estudos

## Resumo Estruturado

### O que é Engenharia de Prompts?
É a prática de estruturar instruções para obter respostas melhores de modelos de IA.

### Principais técnicas
- Contextualização;
- Exemplos Few-shot;
- Definição de papel;
- Restrições claras;
- Refinamento iterativo.

### Uso no Desenvolvimento
A IA pode auxiliar em:
- geração de código;
- documentação;
- debugging;
- testes;
- arquitetura.

# 📘 Glossário

| Termo | Definição |
|---|---|
| Prompt | Instrução enviada para IA |
| Few-shot | Técnica com exemplos |
| Hallucination | Resposta incorreta da IA |
| Context Window | Quantidade de contexto suportado |
| RAG | Recuperação de informação externa |
